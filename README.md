# Business Central Updates

Bilingual, searchable feature archive for Microsoft Dynamics 365 Business Central.

## Contents

- `index.html` is a self-contained static website. It includes the current feature dataset and runs without a build step.
- The page supports Italian and English UI, free-text search, major/minor release filters, area filters, release ordering, and feature details with Microsoft source links.

## Preview

Open `index.html` in a browser, or publish the repository with GitHub Pages from the `main` branch and repository root.

Live Sites version: https://business-central-updates.vanni-martignago.chatgpt.site/
